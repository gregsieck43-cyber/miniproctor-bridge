# miniproctor bridge

This repository contains the PC bridge distributed with the 智能体遥知 WeChat mini program.

## v0.6.0-rc1 preview

Download the four assets attached to the [v0.6.0-rc1 release](https://github.com/gregsieck43-cyber/miniproctor-bridge/releases/tag/v0.6.0-rc1). Verify the ZIP against its `.sha256` file, then follow `README-RELEASE.txt` in the archive. Node.js 22 or newer is required.

This is a preview bridge build. The V1.2 product release is still blocked by real device and multi Agent acceptance tests. A product appearing in the Agent catalog does not mean it can start or control a real session; unverified capabilities remain disabled.

Source provenance: the archive manifest records the mini program workspace commit used to build this package. The release tag points to the matching distribution source in this repository.
