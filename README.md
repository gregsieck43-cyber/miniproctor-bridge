## Latest preview: v0.6.0-rc27

Download the four assets attached to the [v0.6.0-rc27 prerelease](https://github.com/gregsieck43-cyber/miniproctor-bridge/releases/tag/v0.6.0-rc27). Verify the ZIP against its .sha256 file, then follow README-RELEASE.txt. ZIP: 390894 bytes. SHA-256: a928378b3241fd678483c64d7e1c34150349c0c32e556963910fb3cb14de6e23. [v0.5.1](https://github.com/gregsieck43-cyber/miniproctor-bridge/releases/tag/v0.5.1) remains the stable rollback build.

Windows force stop now checks an invariant full-precision UTC root creation token and a bounded process-tree snapshot. Every parent-child edge must have a unique readable identity and a child no older than its parent. Missing, ambiguous or changed identity refuses tree termination. Real normal-profile Codex CLI 0.155.1 and Qwen Code 0.24.6 active process stops succeeded through simulator SDK -> real development cloud -> PC bridge after this change. Six additional real model replies and arithmetic markers were read successfully. The query-to-taskkill interval is not atomic; background processes after root exit, PID-reuse kill races and other operating systems remain unverified. Existing capability freezes, single-turn EOF, Claude notification filtering, Continue JSON, late-stop history and Cline local backend fixes remain included.

The first-release scope is 25 Agent products. Normal registered profile create/read/active-stop checks currently cover 15 products. Windsurf/Devin and Comate are excluded candidates with capabilities disabled. Phone, second-user, remaining-product safety/authentication, full concurrency/recovery/operations and platform acceptance remain incomplete. Windows two/four/eight-task concurrency slices were measured; they are not full T22 acceptance. This is a technical prerelease, and V1.2 remains NO-GO. Third-party CLIs, model keys, account logins and device credentials are not bundled. Node.js 22 or newer is required. Stable v0.5.1 and all earlier preview assets remain available.
